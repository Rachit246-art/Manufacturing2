## 🚀 Overview

FORGEX is an ultra-premium, multi-page international industrial manufacturing website engineered using modern HTML5, CSS3, and Vanilla JavaScript. Built with high precision, bespoke asymmetrical compositions, dynamic telemetry HUD overlays, active robotic welding sparks simulation, and interactive engineering tools.

## ⚡ Interactive Features

- **Robotic Welding Spark Particle System**: Real-time canvas particle physics simulating industrial welding sparks.
- **Interactive Metrology Inspection Lab**: Coordinate Measuring Machine (CMM) coordinate scanner with dynamic acoustic wave simulation.
- **Tolerance & Lead-Time Estimator**: Configurable precision engineering quote estimator widget.
- **Interactive Carbon Impact Simulator**: Dynamic ESG sustainability calculator with live energy and CO₂ offset metrics.
- **Interactive Milestone Timeline**: 1998–2026 chronological company evolution with rich telemetry.
- **Live World Clocks**: Real-time operating timezones for global hubs (Munich, Detroit, Tokyo, Singapore).
- **Responsive Architecture**: Fluid scaling across mobile, tablet, laptop, and ultra-wide screens.
